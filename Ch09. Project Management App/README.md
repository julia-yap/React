### The Process
1. Add a sidebar
2. Add projects. Create reusable input components.
3. Manage state to toggle the UI between viewing and editing projects.
4. useRef to collect user input.
5. Update UI per edits on project data.
6. Close new project form when saved with valid ata.
7. Show the new project in the sidebar.
8. Validate inputs and show error modal.
9. View a project's information.
10. Add and delete tasks.
